## 1️⃣ 环境

- 📦 Python 相关包

	```Shell
	Set-Location D:\kao\PNP

	conda create -n PNP python=3.11 pip -y
	conda activate PNP
	python -m pip install -r .\requirements.txt
	```

- 💻 系统依赖

    安装以下工具，并将其加入 `System PATH`：

    - **TeX Live**
    - **pdftocairo**
